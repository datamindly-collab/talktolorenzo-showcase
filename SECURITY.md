# Security and responsible disclosure

This is a documentation-only public showcase. It does not contain the production TalkToLorenzo source code, infrastructure configuration, credentials, proprietary prompts, or user data.

If you believe you have found a security or privacy issue related to the live product, please do not disclose it publicly in a GitHub issue. Contact:

**balint@bestofyou.io**

Please include a clear description of the issue, reproduction steps where appropriate, and the potential impact. Do not access, alter, retain, or share data that does not belong to you.
